# SignBridge+ Roadmap

## Stage 0 — Feasibility

Prove:
- landmarks
- DTW
- few-shot
- local recognition

## Stage 1 — Prototype

Add:
- learned encoder if justified
- Teach Mode
- recognition UI
- TTS
- offline

## Stage 2 — Hackathon MVP

Add:
- stronger robustness
- curated ISL vocabulary
- benchmark instrumentation
- polished UX
- demo mode

## Stage 3 — Advanced product

Potential:
- two-way communication
- on-device ASR
- phrase chaining
- more robust signer adaptation
- multilingual output
- larger gesture libraries

## Stage 4 — Research/product scale

Potential:
- continuous sign recognition
- facial/body grammar
- open-vocabulary gesture learning
- personalized models
- accessibility studies

None of Stage 3/4 should compromise the hackathon MVP.
