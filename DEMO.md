# SignBridge+ Demo Plan

## Core demo

### 0–5s — Hook

> "Can you teach our phone a new gesture in 30 seconds?"

### 5–25s — Teach

Judge performs the gesture three times.

### 25–30s — Label

Judge selects:
`Emergency`

### 30–40s — Learn

Phone:
> Gesture learned ✓

### 40–50s — Recognition

Judge repeats.

Phone:
> EMERGENCY

### 50–55s — Speech

Phone says:
> "Emergency."

### 55–65s — Offline proof

Disable connectivity.

Judge repeats.

Phone still recognizes.

## Closing

> "The phone didn't need to know the gesture beforehand. You taught it."

Then:

> "We're applying the same mechanism to Indian Sign Language communication."

## Backup

If the judge refuses:
- trained teammate demonstrates
- then offer judge a second attempt if time allows

Never make the demo entirely dependent on judge participation.

## Demo rules

- no architecture slides before the WOW
- no fake metrics
- no cloud dependency
- no long setup
- keep UI large and readable
- prepare a backup recording
- test brightness and do-not-disturb
